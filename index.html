StorageFile

API de armazenamento de arquivos simples e rápida — segura com path embaralhado, senha na URL e criptografia

📌 Visão Geral

O StorageFile permite salvar (POST) e ler (GET) arquivos. Cada URL representa o caminho completo no servidor (pasta + arquivo). Para maior segurança, recomenda-se usar path embaralhado e/ou senha dentro da URL:

https://api-storagefile.onrender.com/${SENHA}/arquivo.txt
⚠️ Importante: O uso de senha no path não substitui autenticação real, mas adiciona uma camada de segurança. Combine com HTTPS, tokens e criptografia (AES + Base64) para máxima proteção.

🔒 Segurança Interna

O StorageFile conta com múltiplas camadas de segurança:

  • Path embaralhado: pastas podem ter nomes randômicos para impedir adivinhação.
  • Senha na URL: adiciona chave de acesso extra (/API_KEY/arquivo.txt).
  • Criptografia: arquivos podem ser armazenados com AES e transferidos em Base64.
  • Checksums: verificação de integridade evita alterações maliciosas.
🔑 Exemplo de caminho seguro: 
https://api-storagefile.onrender.com/AB12xyZ9/${SENHA}/dados_usuario.txt

⚙️ Endpoints

POST — Upload

POST https://api-storagefile.onrender.com/<SENHA>/<arquivo>.txt

Body: Arquivo binário (UTF-8 ou qualquer formato) até 5 GB.

GET — Download

GET https://api-storagefile.onrender.com/<SENHA>/<arquivo>.txt

Retorna application/octet-stream ou text/plain dependendo do arquivo.

🛠️ Exemplos em várias linguagens

cURL

# Upload
curl -X POST "https://api-storagefile.onrender.com/SEGREDO/nota.txt" --data-binary @meuarquivo.txt

# Download
curl "https://api-storagefile.onrender.com/SEGREDO/nota.txt" -o baixado.txt

JavaScript (fetch)

const formData = new FormData();

Node.js (fs stream)

import fs from "fs";

Python (requests)

import requests
with open("meuarquivo.txt","rb") as f:
    requests.post("https://api-storagefile.onrender.com/SEGREDO/nota.txt", files={"file": f})

Ruby

✅ Boas Práticas

  • Use paths embaralhados (UUID ou randomBytes) + senha.
  • Sempre HTTPS.
  • Arquivos sensíveis: criptografia em repouso (AES + Base64).
  • Armazene metadados (owner, checksum, data) em DB.
  • Implemente logs e auditoria se uso profissional.

Resumo Rápido

  • API: StorageFile
  • Upload: até 5 GB
  • Path seguro: /${SENHA}/arquivo.txt
  • Formato: application/octet-stream
  • Segurança: Criptografia AES + Base64, checksums
Combine senha + path embaralhado para máxima segurança.
