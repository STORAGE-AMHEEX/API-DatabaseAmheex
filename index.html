GET (Ler)  |  POST / PUT (Gravar)  |  DELETE (Remover)

Resumo Rápido (Métodos HTTP)

Método GET (Leitura)

Lê o conteúdo do arquivo JSON armazenado na rota correspondente dentro da pasta interna X/.

GET https://api-databaseamheex.onrender.com/usuarios/perfil

Se o arquivo não existir, a API retorna null automaticamente.

Método POST / PUT (Gravação)

Grava dados enviados (em formato JSON ou texto bruto) criando automaticamente os diretórios necessários.

POST/PUT https://api-databaseamheex.onrender.com/usuarios/perfil
Comportamento de Extensões:
• Se a URL acessada não possuir extensão, a API adiciona automaticamente .json.
• Arquivos terminados em .php são automaticamente neutralizados para .php.txt por segurança.

Operações da API

1. GET - Ler dados

Retorna o JSON salvo no caminho especificado ou null se vazio/inexistente.

fetch("https://api-databaseamheex.onrender.com/dados/config")
  .then(res => res.json())
  .then(data => console.log(data));

2. POST / PUT - Salvar ou Atualizar dados

Envia dados para serem salvos na árvore de diretórios do servidor.

fetch("https://api-databaseamheex.onrender.com/dados/config", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ tema: "escuro", ativo: true })
})
.then(res => res.json())
.then(data => console.log("Salvo:", data));

3. DELETE - Remover dados (Simula .remove())

Apaga o arquivo correspondente do servidor.

fetch("https://api-databaseamheex.onrender.com/dados/config", {
  method: "DELETE"
})
.then(res => console.log("Removido com sucesso"));
